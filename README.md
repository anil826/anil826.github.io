# Anil Yadav — Portfolio

A professional, minimal portfolio for Senior Salesforce Developer Anil Yadav. The site is plain HTML, CSS, and JavaScript, so it can be hosted directly on GitHub Pages without a build step.

## Files

- `index.html` — portfolio content and structure
- `styles.css` — responsive light/dark design
- `script.js` — theme switcher and current year
- `favicon.svg` — AY site icon
- `PROFILE_README.md` — content for the `anil826/anil826` profile repository

## Publish the portfolio

1. Create a public GitHub repository named `anil826.github.io`.
2. Upload the files from this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. The site will be available at <https://anil826.github.io> after GitHub completes deployment.

## Publish the profile README

1. Create a public repository named exactly `anil826`.
2. Copy `PROFILE_README.md` into that repository as `README.md`.
3. Commit the file. GitHub will display it on <https://github.com/anil826>.

## Local preview

Open `index.html` in a browser. No package installation or build command is required.

## Privacy

The public site does not include a phone number or email address. Client-specific implementation details are anonymized.
